The first reviewed wave covers MCP tools, MCP Apps, workspace files, terminal commands, computer use, and Agent Skills across selected exact harness surfaces. Every non-unknown statement records a target, environment profile, structured conditions, dated notes, and typed public evidence.

The site now exposes twelve revision-aware specification references, an evidence ledger, a proposed-but-not-run conformance test registry, an ecosystem change feed, and a contradiction register. HTML, Markdown, JSON, OpenAPI, sitemap, and `llms.txt` surfaces are generated from the same catalog records.

Unknown remains the default. Documentation evidence remains distinct from runtime testing, and the product publishes no synthetic compatibility score or fabricated usage share.
