Start with something you want done: find a note, summarize an issue, organize a workspace, or book two movie seats. Then look for an app with a documented way for your agent to do that specific job.

[Explore apps in the catalog](/products). Each app record separates the connection route from the work it enables, with source links and review dates.

## Read the four steps separately

An app can be useful to an agent even when you need to create the account or approve the connection yourself. Check each part:

1. **Sign up:** Can the agent create an account, or do you need to start with an existing one?
2. **Connect:** Is there a documented MCP, API, CLI, browser, or file route? What authorization and setup does it require?
3. **Buy or subscribe:** Is purchasing assessed separately? Working inside an app does not establish that an agent can pay for a plan.
4. **Do useful work:** Which actions are covered, and what limits apply to the connected account?

A “human step” identifies where you need to help. “Unknown” means the catalog does not establish that part of the workflow.

## Match the route to your agent

A connection only helps when your agent can use it. A command-line tool needs an agent with terminal access. An MCP connection needs a compatible client and the transport the service uses. A file workflow needs access to the files you select.

Open the app's guide and follow the documented route that fits your setup. If you need to check an agent capability, use the [agent catalog](/harnesses) or [ask through the Can My Agent Use plugin](/plugin).

## Start with a small, specific request

After connecting an app, try a task with a result you can inspect:

> “Find the notes about this project and summarize them with links to the originals.”

Or:

> “Read this issue and summarize the open questions before proposing changes.”

Check that the agent sees the intended workspace and has the access the task requires. A listing in the catalog describes the documented route; it does not inspect your connection or confirm your account permissions.

## Before you rely on the answer

Read the app record's scope, source links, and review date. Keep plan restrictions, organization policies, platform requirements, and human handoffs attached to the recommendation. A documented integration and a completed transaction are different kinds of evidence.
