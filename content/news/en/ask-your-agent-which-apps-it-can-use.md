You can now ask an agent to look up apps in Can My Agent Use and bring back the details that matter: what it can do, how to connect, where you need to help, and which sources support the answer.

[Get the plugin and connection instructions](/plugin).

## Try an app question

> “Find apps for notes and knowledge work. Explain the connection options and any setup I need to do.”

Then narrow the task:

> “Open the full record for the app I choose. Separate account setup, connecting, purchasing a plan, and doing useful work.”

The plugin searches the published catalog and retrieves complete records. It can also check a particular capability against an exact web, desktop, or CLI agent surface.

## Ask for the evidence, too

> “Include the source links and review dates. Tell me what is documented, what is tested, and what is still unknown.”

The response should keep requirements and limitations beside the recommendation. Search results help you find a record; the full record explains its scope.

## Connect once, then use the catalog

Install the plugin in a compatible host, or add **https://canmyagentuse.com/mcp** through your agent's remote MCP settings using Streamable HTTP. The catalog connection is public and does not need an account or API key.

This connects your agent to the catalog. Connecting to a recommended app is a separate step, with that app's authorization and permissions. The lookup tools do not sign into accounts, buy subscriptions, or install integrations.

The [installation guide](/plugin) includes the downloadable plugin and MCP configuration. If you prefer to browse, [explore the apps directly](/products).
