Provider-level security pages are not automatically harness-level evidence. A useful record follows prompts, uploaded files, repository content, retrieved data, tool results, generated artifacts, telemetry, feedback, abuse-monitoring copies, and backups through the exact web, desktop, editor, or CLI execution path.

Each child row keeps plan, organization setting, region, account type, connector, model endpoint, local or hosted execution, and review date attached. “Enterprise ready” and a list of compliance certifications are not substitutes for operational controls an evaluator can verify.
