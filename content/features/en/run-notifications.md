This row asks whether the harness can tell the responsible operator that unattended work completed, failed, stalled, hit a budget or quota, or needs approval. An in-app badge visible only after reopening the product is narrower than an external actionable notification.

Evidence should record supported channels, event types, user and project routing, quiet hours, escalation, deduplication, links back to the exact run, sensitive-content redaction, access checks, webhook signing, retry behavior, and notifications generated by sub-agents.
