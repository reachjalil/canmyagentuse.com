Can My Agent Use is an independent compatibility catalog for engineers choosing an agent product. It answers one question: **does this exact product support this capability, and which public source supports the status?**

The task is familiar: search a capability, scan web, desktop, and CLI columns, read the limits, and open the cited source. Caniuse.com inspired that lookup–compare–cite information structure. The publication's visual identity, research, and editorial work are its own.

## Who it serves

People can use the search, matrices, product pages, specification index, evidence ledger, contradiction register, test definitions, and comparison table. Agents can start at `/llms.txt`, fetch a `.md` copy, or query the versioned JSON API. Every format comes from the same content records. Machine-readable copies do not receive different claims.

## What the table promises

Unknown is the default. A cell changes only when a dated note cites public evidence for one capability revision, exact product target, and environment profile. Partial means the capability has a documented limit. The sourced-cell percentage measures catalog completeness. It does not measure adoption, popularity, quality, conformance, or market share.

The catalog separates workspace instructions, skills, package formats, tool protocols, web exposure, interactive UI, editor protocols, session hosts, and agent-to-agent exchange. A claim about one layer does not prove support for another. A brand-level claim does not prove every child capability.

## Independent by design

Can My Agent Use publishes its own research, methodology, interface, and editorial voice. Product names and compact brand marks help readers find the right catalog record; they remain the property of their respective owners.
