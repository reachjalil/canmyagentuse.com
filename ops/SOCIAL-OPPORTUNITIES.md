# Conversation workflow entry point

The maintained workflow is [conversations/README.md](conversations/README.md),
with the current queue in [conversations/INDEX.md](conversations/INDEX.md).

The owner now wants three independently assignable jobs: extensive conversation
research, discussion-informed site improvements, and personal/brand contribution
lists. Discovery should preserve a broad useful pool and thread context, not
stop at twenty or draft promotional replies automatically. Use the best tools
available to the assigned agent. Exact evidence, dates, ownership and actual
outcomes are recorded in the shared Markdown contract.

The three Harness-managed skills are `cmau-find-conversations`,
`cmau-discussion-to-site` and `cmau-compose-replies`. Prefer the new task files
over earlier one-off prompts. Keep the existing daily automation; do not create
a second publisher. No posting is authorized by this research workflow.
